# 🌤️ Modern Weather App

A lightweight, fully responsive, and modern Weather Application built with **HTML5, CSS3, and JavaScript**. It fetches live weather data using the **Open-Meteo API** without requiring any API keys or sign-ups.

---

## 🌟 Features

- 🔍 **City Search:** Search weather conditions for any city globally.
- 🌡️ **Live Temperature & Condition:** Displays real-time temperature and weather descriptions (Clear, Rainy, Cloudy, etc.).
- 📊 **Detailed Weather Stats:**
  - **Feels Like** temperature
  - **Humidity** percentage
  - **Wind Speed** (km/h)
- 📱 **Responsive UI:** Glassmorphism modern dark-theme design that adapts to mobile, tablet, and desktop screens.
- ⚠️ **Error Handling:** Clear notification messages for empty inputs or invalid city names.
- ⚡ **No API Key Required:** Uses Open-Meteo's free public weather API.

## 🛠️ Technologies Used

- **HTML5** – Semantic page structure
- **CSS3** – Glassmorphism UI layout & CSS Flexbox/Grid
- **JavaScript (ES6)** – DOM manipulation and event handling
- **Fetch API** – Asynchronous API calls using Promises (`.then()`)
- **Open-Meteo API** – Free Geocoding and Weather Data API
